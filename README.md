# Muse Multi Studio

Ứng dụng Windows tạo ảnh/video AI đa luồng, backend FastAPI + SQLite, giao diện Dark Pro.

**Phiên bản:** 0.2.0 (beta). Nhà cung cấp AI hỗ trợ qua API: fal.ai (tạo ảnh/video) và OpenAI (tạo/chỉnh ảnh). Chức năng AI thực yêu cầu API key hợp lệ; không có dữ liệu giả khi chạy sản phẩm.

**Trạng thái phát hành:** Đang triển khai toàn bộ mã nguồn và workflow build Windows. Chỉ sử dụng EXE sau khi job kiểm thử Windows hoàn thành thành công.

Không đưa API key, `muse.db`, `credential.key`, `.env`, hoặc tệp tài khoản cá nhân lên repository này.

Tài liệu đầy đủ trong `README.md` sau khi quá trình nhập mã nguồn hoàn tất.

_Đây là dự án phát triển độc lập, không phải mã nguồn chính thức của sản phẩm Muse Studio xuất hiện trong ảnh tham chiếu._
